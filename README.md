# (retired) osmgeoweek.org website

OSMGeoWeek is an annual worldwide celebration of open mapping that takes place each November since 2014. In 2020, OpenStreetMap US took over the responsibility of organizing the event. This Jekyll codebase was used for the [osmgeoweek.org](https://osmgeoweek.org) website between 2020 and 2024.

OpenStreetMap US continues to organize OSMGeoWeek each year, but this website has been retired. Information about the event can now be found at [openstreetmap.us/events/osmgeoweek/](https://openstreetmap.us/events/osmgeoweek/), and the [osmgeoweek.org](https://osmgeoweek.org/) domain simply redirects there.
